# ADR-0004: محرك التنزيل وسلوك المنصات

- الحالة: **مقترح؛ يحتاج موافقة**
- التاريخ: 2026-11-07

## السياق

تختلف صلاحيات الملفات والعمل بالخلفية بين تطبيقات سطح المكتب والويب وAndroid. لا يمكن لواجهة ويب عامة أن تفترض الكتابة المباشرة إلى مسارات نظام الملفات أو التشغيل المستمر بعد إغلاق الصفحة.

## الخيارات

1. نقل HTTP مشترك مع موائمات كتابة وحفظ لكل منصة.
2. الاعتماد على مدير التنزيل الأصلي لكل نظام.
3. تنزيل الملفات عبر خدمة وسيطة سحابية.

## القرار المقترح

الخيار 1 للنسخة الأولى: نقل HTTP داخل التطبيق، مع موائم تخزين لكل منصة، واستخدام واجهات اختيار/تنزيل الملفات التي يوفرها المتصفح في الويب. لا خدمة وسيطة ولا استيراد تلقائي من صفحات المواقع.

## السبب

يحافظ على خصوصية التنزيلات محليًا ويبقي النطاق صغيرًا، مع عزل الفروق الخاصة بكل نظام.

## الأثر والتحقق

يجب تحديد دعم إعادة التوجيه، وبيانات الاعتماد، وطلبات النطاق، والإيقاف والاستئناف، والتحقق من الوجهة النهائية. يمنع الوصول إلى الشبكات الخاصة أو عناوين loopback عبر الروابط وإعادة التوجيه ما لم يُعتمد استثناء صريح. الويب لن يعد بالعمل بالخلفية. هذه السياسات لم تُنفذ ولم تُختبر؛ يلزم تصميم تهديد واختبارات قبل إطلاق التنزيل.
