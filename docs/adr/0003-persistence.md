# ADR-0003: حفظ البيانات

- الحالة: **مقترح؛ يحتاج موافقة**
- التاريخ: 2026-11-07

## السياق

يحتاج التطبيق إلى حفظ قائمة التنزيلات وإعدادات بسيطة محليًا. تنزيل الملفات نفسها قد يكون كبيرًا، ولا ينبغي تخزينها داخل قاعدة البيانات.

## الخيارات

1. SQLite محلية لبيانات المهام والإعدادات، والملفات في مجلد يختاره المستخدم.
2. ملفات JSON محلية؛ سهلة البدء لكن تحديثات متزامنة وترحيل البنية أصعب.
3. قاعدة بيانات سحابية؛ تضيف حسابات وخادمًا ومزامنة لم يطلبها النطاق.

## القرار المقترح

SQLite محلية للبيانات الوصفية والإعدادات، والملفات في نظام الملفات أو مخزن الملفات الذي توفره المنصة. يُحصر القرار بواجهة تخزين مجردة ويُختبر على المنصات قبل اختيار مكتبة نهائية.

## السبب

تعمل محليًا دون حساب أو اتصال، وتدعم استعلام قائمة المهام وتحديثها في معاملة. لا تضيف مزامنة غير مطلوبة.

## الأثر والتحقق

يجب تحديد مكان قاعدة البيانات لكل منصة، وترحيل مخططها، والتعافي من ملف قاعدة بيانات تالف، وسياسة حذف سجل المهمة. لا تحفظ أسرارًا أو بيانات اعتماد. اختبار الترحيل والتعافي مطلوب ولم يُختبر.
