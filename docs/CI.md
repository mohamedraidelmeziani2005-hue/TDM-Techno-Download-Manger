# حالة CI في مرحلة التأسيس

يشغّل `.github/workflows/ci.yml` فحص تنسيق ملفات Markdown على Windows وmacOS وLinux مع كل Pull Request. لا يوجد تطبيق أو ملفات اختبارات بعد، لذلك هذا الفحص لا يبني التطبيق ولا يختبر تنزيلات.

تضاف فحوص تحليل التطبيق واختباراته وبناء كل هدف في مرحلة 0/1 بعد اعتماد إطار العمل وإنشاء هيكل المشروع، وقبل تنفيذ ميزات المنتج. لا يجوز اعتبار فحص الوثائق بديلًا عنها.
