# Techno Download Manger

مدير تنزيلات مفتوح المصدر قيد البناء، يتيح للمستخدم إضافة روابط تنزيل مباشرة ومتابعة تقدمها من مكان واحد.
يستهدف الأفراد الذين يريدون واجهة عربية بسيطة على Windows وmacOS وLinux والويب وAndroid، مع إمكانية التبديل إلى الإنجليزية.

## الحالة

**قيد البناء.** هذه النسخة تحتوي وثائق تأسيسية فقط؛ لا يوجد تطبيق بعد، ولم يُختبر أي تنزيل أو إصدار على المنصات المستهدفة.

## النطاق المبدئي المقترح

- إضافة رابط HTTP أو HTTPS مباشر لتنزيل ملف.
- عرض الاسم والحجم والتقدم والحالة، مع قائمة انتظار.
- واجهة عربية افتراضيًا وزر للتبديل إلى الإنجليزية.
- دعم أساسي للملفات المحلية؛ إدارة الحسابات والخدمات السحابية خارج النطاق.

هذه أهداف مقترحة وليست ميزات منفذة. راجع [PRD](docs/PRD.md) والقرارات المقترحة في [سجل القرارات](docs/adr/).
